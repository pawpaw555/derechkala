## 2. "מאיפה אני יוצא" — הפער בזרימה

מהמשתמש, תרחיש מלא:

    יודע שיש אירוע בלוחמים 2 תל אביב
    → נכנס ל-/map, מקליד את הכתובת          ✓ עובד
    → מקבל את התחנה הקרובה                  ✓ עובד
    → לוחץ עליה, מגיע לעמוד התחנה           ✓ עובד
    → לוחץ "תכנן נסיעה לכאן"                ✓ עובד
    → בעמוד הבית: תחנת היעד מוזנת,
      תחנת המוצא ריקה
    → מקליד שם של קיבוץ או מושב             ✗ לא מוצא כלום
    → נשאר רק לפתוח מפה ולחפש ויזואלית

**האבחנה:** באתר יש שני מנועי חיפוש שונים.

    שדות מתחנה/לתחנה  →  34 תחנות + 66 נקודות ציון + 22 מקומות

**הכיוון המוצע:** כששדה "מתחנה" לא מוצא תחנה, שיפנה את אותה שאילתה
לחיפוש המקומות, ויציע "מצאנו את X — התחנה הקרובה אליו היא Y".
